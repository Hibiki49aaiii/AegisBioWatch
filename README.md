# AegisBioWatch

Privacy-first wearable platform for personal baseline monitoring, sleep/wake analysis, physiological sensing, alerts, and local-first data handling.

## Engineering policy

- Rev.0 is an engineering/research wearable, not a diagnostic medical device.
- Physiological algorithms use generalized baseline/anomaly states rather than psychiatric diagnoses.
- Medication reminder/acknowledgement is separated from physiological inference.
- Do **not** commit personal case histories, private messages, medication names/doses, raw voice recordings, or identifying health information.
