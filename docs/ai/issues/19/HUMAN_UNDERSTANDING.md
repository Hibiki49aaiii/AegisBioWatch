## Screening rule
Phase A1 is read-only. It uses the actual reproduced route-1bl board and treats different-net and unnetted copper as obstacles. Same-net copper is context, not an obstacle.

A DRC description or representative coordinate is not electrical authority. Before any materialization, the exact source/target pad or track must be proven from PCB data.

## Rollback
Any failed source gate, screen, refine, exact probe, DRC, 112→111 decrement, audit, scope, or Artifact integrity gate leaves route-1bl unchanged as the accepted authority.


## Phase B outcome
The selected ordinary closure is R305.2/VSYS_HAPTIC to U4.10/VSYS_HAPTIC. It was chosen after proving that the accepted C305/C304 bypass copper and R305.2 are distinct VSYS_HAPTIC source islands, so the route is a pad-to-pad closure rather than an ambiguous T-junction into the existing bypass.

The accepted path is:
`R305.2 (31.315,18.595) -> (31.315,17.500) -> (25.000,17.500) -> (25.000,13.400) -> U4.10 (23.005,13.400)`.

Executed acceptance produced 0 KiCad DRC violations, exactly 111 unconnected items, and a 268-node physical pin/net audit PASS. The exact delta is four 0.30 mm F.Cu tracks, zero vias, zero component moves/rotations, no removed copper, and preservation of the accepted route-1bk bypass. The modeled limiting clearance is 0.200 mm to U4.9/HAPTIC_OUT_N, versus the 0.100 mm requirement.

The first validation run failed before DRC because the delta checker demanded exact decimal identity for regenerated bypass coordinates; KiCad represented 16.005 mm as 16.004999 mm. This was a validation-script false negative, not a route acceptance result. The corrected checker uses a 0.002 mm coordinate tolerance while still requiring exactly one matching bypass segment before and after. The successful rerun and both Artifact verification layers are the authority.

route-1bm is therefore the accepted routing baseline. Manufacturing status remains NOT_FOR_GERBER.
