# Phase 1 Main Board routing safety invariants

Status: active  
Date: 2026-08-20  
Keywords: mainboard, pcb, routing, kicad, drc, audit, rf, gerber, artifact

## Reusable intelligence

- The current Phase 1 PCB is an engineering routing baseline, **not** Gerber/manufacturing authority.
- Promote only one isolated routing increment at a time. Formally accept the current increment before creating the next candidate.
- Executed KiCad 9.0.9 DRC and the repository pin/net audit are acceptance authority for the current routing series; preflight geometry and routing seeds are provenance/input checks only.
- Acceptance requires the exact expected unconnected count, 268-node audit PASS, exact intended routing scope, component identity/net/geometry checks, and zero unintended placement changes.
- RF and supplier-gated interfaces remain frozen until their explicit release gates are satisfied; do not trade those gates for a lower ratsnest count.
- Prefer current source/materializer/Artifact facts over handoff or conversation summaries. Re-open the current evidence when hashes, net names, geometry, or status disagree.
- Historical accepted Artifact byte hashes are provenance. Regenerated byte identity alone is not an electrical acceptance gate.
