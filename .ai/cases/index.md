# Case Memory Index

A Case captures a bounded problem/investigation with enough evidence to avoid repeating the same work. Small cases may use one file; larger cases may use `summary.md`, `evidence.md`, `attempts.md`, and `outcome.md`.

A complete case should cover: problem, context, root cause when meaningful, final solution, status, related files/tests/commit/PR/issue; verified evidence; meaningful attempts and failed hypotheses; final verification, remaining risk, follow-up, and reusable lessons.
